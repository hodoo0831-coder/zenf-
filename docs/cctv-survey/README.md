# 현장 CCTV 설치 장소(위치) 조사 — 제니엘 버전

원본(아모레퍼시픽 템플릿, 3장)을 제니엘 브랜딩으로 교체하고 보고서 구성으로 보완한 산출물.

## 산출물
- `CCTV_설치위치_조사_제니엘.pptx` — 최종 8장 구성

## 슬라이드 구성
1. 표지 (제니엘 워드마크)
2. 조사 개요 — 목적 / 배경 / 범위 / 방법 + 수량 요약
3. 설치 위치 총괄 — 8개소 표 + 확인 필요사항
4. 포장재창고 1층·도크장 7대 (원본 도면·현장사진 유지)
5. 포장재창고 2층 1대 (원본 도면·현장사진 유지)
6. 설치 시 검토사항 — 전원·통신 / 화각·사각지대 / 설치환경 / 작업안전
7. 개인정보보호 준수사항
8. 추진 일정 및 협조 요청

## 재생성 방법
원본 pptx를 `orig.pptx`로 두고 같은 디렉터리에서 실행한다.

```bash
python3 debrand.py   # AP 브랜딩 제거 + 제니엘 푸터 삽입 -> base.pptx
python3 make.py      # 표지 재구성 + 신규 슬라이드 추가 -> 최종 pptx
```

## 참고
- 제니엘 워드마크는 텍스트 기반이다. 공식 CI 로고 이미지가 있으면 표지·푸터의 텍스트를 교체하면 된다.
- 배치 도면 이미지 자체에 남아 있는 발주처 도면 관리 워터마크는 원 도면의 문서관리 표시이므로 그대로 두었다.
