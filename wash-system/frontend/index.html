📖 v2.1 변경 사항 (NEW)

⭐ 필요 시간(수기→디지털) — 생산라인 및 설비가 도착 등록 시 "X시까지 완료" 직접 입력

⭐ 점도/제품 선택 — 안(C1~C5) + 제품타입(1제, 2제, 파우치 등) 둘 다 선택

⭐ AP 필요시간 준수율 — 홈 KPI에 새 지표 추가 (BY27 협상 핵심)

⭐ 지연/여유 자동 계산 — 필요시간 대비 실제 완료 시각 차이 기록 (Delay_Min)

📖 v2 기본 기능

① 2계정 시스템 — 생산라인 및 설비(도착 등록) / 세척실(시작·종료) 별도 화면

② 3단계 추적 — 도착(T2) → 세척시작(T3) → 세척종료(T4)

③ 대기시간 KPI — 도착~세척시작 시간을 자동 측정

④ 66개 라인 검색·즐겨찾기 — 자주 쓰는 라인 자동 상위 노출
