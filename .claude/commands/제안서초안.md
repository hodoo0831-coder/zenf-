# 사업 제안서 작성 자동화 파이프라인 (3강 데모 2)

## 트리거
제안요청서 파일 업로드 + `/제안서초안` 입력 (이벤트 기반 트리거)

## 단계
1. **분석** — `rfp-proposal` Skill 1단계로 요구사항·평가기준·마감일·제출형식 추출
2. **작성** — 동 Skill 2단계 표준 목차로 초안 작성
3. **검증 (필수·생략 불가)** — 요구사항 1:1 대조 + 평가기준별 대응 여부 확인
4. **보고** — 누락·불충분 1건이라도 있으면 완료 처리하지 말고 표로 보고 후 정지
5. **저장** — 신규 파일로만 저장

## 판단 기준
- 요구사항 누락 0건
- 평가 기준 전 항목에 대응 내용 존재
- RFP에 없는 내용 창작 0건 (자사 정보는 `[회사 정보 입력]` 표기)

## 제약
- 기존 파일 덮어쓰기 금지
- **외부 자동 발송·전송 동작 절대 포함 금지**
- 빠진 정보가 있으면 만들기 전에 먼저 질문
