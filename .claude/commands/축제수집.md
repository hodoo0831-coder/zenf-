# 지역 행사 마케팅 자동화 파이프라인 (3강 데모 3)

수집 범위: 오늘부터 **$1일** (미입력 시 7일)

## 스케줄 3건 (교재 48pg 구성)
| 시각 | 작업 | 사람 개입 |
|---|---|---|
| 08:00 | 축제 수집 + 노션 일별 페이지 생성 + 메일 발송 | 결과 확인 |
| 08:20 | 관심 주제 선정 + 한글 블로그·인스타 초안 + 메일(PDF) | **컨펌 필요** |
| 09:10 | 컨펌 시 4개 언어 번역 + SEO/AEO/GEO 적용 + 노션 게시 | 사후 확인 |

> 컨펌 없이 09:10 작업이 자동 진행되지 않게 한다. 데모에서 '컨펌 간주'로 돌릴 때는
> 그 사실을 산출물에 명시한다.

## 단계
1. `festival-collector` Skill 1단계 — TourAPI 수집 (인증키는 환경변수)
2. 유형 분류 — 전통문화 / K-컬처 / 자연
3. 노션 일별 페이지 **신규 생성** + 출처 표기
4. 관심 주제 선정 → 한글 블로그 + 인스타 이미지 텍스트 초안
5. **정지 — 사람 컨펌 대기**
6. 컨펌 후: 영어·일본어·중국어(간체·번체) 번역 + 노션 종합/개별 페이지 생성

## 판단 기준
- 수집 건수 > 0, 전 항목 출처 표기
- 한글 초안이 컨펌 전 번역·게시되지 않았을 것
- 산출물 어디에도 인증키가 남지 않았을 것

## 제약
- 링크(URL) 연결은 1차에서 제외 — 교재 지시대로 초안 단계에서는 URL을 붙이지 않는다.
- 외부 발송은 사람 승인 후. 기존 노션 페이지 덮어쓰기 금지.
