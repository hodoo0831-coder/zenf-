# 리서치 요약 자동화 파이프라인 (3강 데모 1)

주제: **$1**

## 목적
매주 반복하는 리서치를 트리거 한 번으로 팀 공유용 발표자료까지 만든다.

## 단계

### 1. 수집 — `research-collector` 서브에이전트
"$1" 주제로 최신 자료 수집. 최근 6개월 이내 우선, **모든 자료에 출처 URL 필수**.

### 2. 요약 — `research-summary` Skill
핵심요약 3줄 / 주요동향 5개 / 시사점 2~3개 / **출처 목록**(필수).

### 3. 노션 정리 — Notion 커넥터
지정한 노션 페이지 하위에 `[YYYY-MM-DD] $1` 페이지를 **새로 생성**한다.
요약 본문 + **출처 목록 섹션을 반드시 포함**한다. 기존 페이지 수정 금지.

### 4. 슬라이드 — PPT 생성 Skill
요약 결과를 슬라이드로 만든다. **마지막 장은 항상 출처 슬라이드**.
파일명 `YYYYMMDD_리서치_$1_v1.pptx`, **신규 파일로만 저장**.

### 5. 검증 (정지 지점)
1. 모든 주장·수치에 출처가 붙어 있는가
2. 노션 페이지와 PPT 마지막 장에 출처 목록이 들어갔는가
3. 기존 파일·페이지를 덮어쓰지 않았는가

하나라도 실패하면 **저장하지 말고 보고**한다.

## 제약
- 확실하지 않은 내용은 지어내지 말고 `확인 필요` 로 표시한다.
- 각 단계 결과를 간단히 보고하고, 문제가 있으면 멈춰서 먼저 알린다.
- 외부 자동 발송 금지.
