# 월 마감 정산자료 파이프라인 (UC-01)

대상 월: **$1**

## 목적
4개 계약의 마감 집계를 매월 동일 기준으로 작성한다. 작성공수 48H → 12H, 본사 반려 0건.

## 처리 절차

### 1. 입력 확인 (정지 지점)
업로드된 원장 파일이 아래 4축을 모두 포함하는지 확인한다. 하나라도 없으면 **집계하지 말고 즉시 보고**한다.
- 아모레퍼시픽 생산도급 / 아모레퍼시픽 업무도급
- 코스비전 생산도급 / 코스비전 업무도급

전월과 원장 컬럼 구조가 다르면 진행 전에 먼저 질문한다.

### 2. 계획 제시
집계 항목·산출 파일명을 요약해 보여주고 승인을 받은 뒤 실행한다.

### 3. 파싱 (수집 서브에이전트)
계약 4축으로 **분리** 파싱한다. 두 고객을 합산하지 않으며, 출처를 컬럼으로 남긴다.
계약 식별이 불가능한 행은 격리해 별도 목록으로 보고한다.

### 4. 집계 (xlsx Skill)
계약별 근태·공수·LOSS·인원을 집계한다. 코스비전 세탁실은 별도 정산 항목으로 분리한다.

### 5. 검증 (정지 지점)
아래 3개를 모두 확인한다. **하나라도 걸리면 저장하지 말고 보고**한다.
1. 계약별 인원 합계 = 재적 인원 일치
2. 전월 대비 공수 증감 ±15% 초과 항목 없음 (있으면 플래그)
3. LOSS 공수 합계 = MES 원본 합계 일치

### 6. 저장
`$1_[고객]_[계약유형]_마감_v1.xlsx` 로 **신규 파일**만 생성한다.

## 제약
- 읽기 + 신규 파일 생성만. 원본 원장 수정·삭제 금지, 기존 파일 덮어쓰기 금지.
- 근태 데이터는 개인정보다. 사내 처리 한정, 외부 전송 금지.
- 본사 제출은 센터장 승인 후 사람이 직접 수행한다.
- 빠진 정보가 있으면 만들기 전에 먼저 물어본다.
