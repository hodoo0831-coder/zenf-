# 지역 행사·축제 수집 Skill (3강 데모 3)

## 인증키 취급 (중요)
인증키는 **절대 파일·산출물·노션에 기록하지 않는다.** 환경변수 `DATA_GO_KR_KEY` 로만 읽는다.
교재에 인쇄된 키는 강의용이므로 실제 운영에는 본인 계정 키를 사용한다.

## 1단계 — 수집
`python3 scripts/fetch_festivals.py --days 7 --out out/festivals.json`

- 엔드포인트: `https://apis.data.go.kr/B551011/KorService2` / `searchFestival2`
- 결과가 0건이거나 `resultCode`가 정상이 아니면 **다음 단계로 넘어가지 말고 보고**한다.

## 2단계 — 분류
행사 유형을 **전통문화 / K-컬처 / 자연** 3종 + 기타로 분류한다. 분류 근거(매칭 키워드)를 함께 남긴다.

## 3단계 — 노션 정리
- 일별/주별/월별 페이지를 **새로 생성**한다(기존 페이지 수정 금지).
- 각 행사에 출처(TourAPI + 수집일시)를 표기한다.

## 4단계 — 콘텐츠 초안 (한글 먼저)
외국인 관광객 관심도가 높은 주제를 선정해 블로그 글 + 인스타그램 이미지 텍스트를 작성한다.
- 블로그는 SEO/AEO/GEO를 고려한다 (검색 질의형 소제목, 요약 답변 블록, 지역명·좌표 정보 포함).
- **1차 산출물은 한글.** 사람 컨펌 전에는 번역·게시 단계로 넘어가지 않는다.

## 5단계 — 다국어 (컨펌 후에만)
영어 · 일본어 · 중국어(**간체·번체 모두**) 4종. 고유명사는 원문 병기.

## 검증 (정지 지점)
1. 수집 건수 0건 → 정지
2. 출처 미표기 항목 존재 → 정지
3. 사람 컨펌 없이 번역·게시 단계 진입 시도 → 정지
4. 산출물·로그에 인증키 문자열이 포함되면 → 즉시 정지

## 금지
- 외부 자동 발송·게시 (메일·노션 게시는 사람 승인 후)
- 기존 노션 페이지 덮어쓰기
- 원문에 없는 행사 정보 창작
