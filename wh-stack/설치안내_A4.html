포장재 창고 적치 관리 시스템 — 설치 안내

제니엘 제조사업부 사업3팀
기획·제작 이민아
wh-stack.netlify.app
휴대폰 카메라로 왼쪽 QR을 비추거나 주소를 직접 입력하세요.
접속하면 현장 입력과 관리자 중 선택하는 화면이 나옵니다.

1. 휴대폰에 앱처럼 설치하기

i 아이폰 (Safari)
  1. Safari로 wh-stack.netlify.app 접속
  2. 화면 아래 공유 버튼 누르기
  3. 목록에서 홈 화면에 추가 선택
  4. 이름 확인 후 추가
A 안드로이드 (Chrome)
  1. Chrome으로 wh-stack.netlify.app 접속
  2. 우측 상단 ⋮ 메뉴 누르기
  3. 홈 화면에 추가 또는 앱 설치 선택
  4. 이름 확인 후 추가
설치하면 창고 모양 아이콘이 생기고 주소창 없이 앱처럼 열립니다. 현장 담당자는 포털에서 「현장 입력」을 연 뒤 홈 화면에 추가하면 바로 입력 화면으로 뜹니다.

2. 처음 한 번만 하는 설정

구분할 일
현장 담당자 앱 우측 상단 설정 → 이름 입력 후 저장. 서버 주소는 이미 들어 있으므로 건드리지 않습니다.
관리자 포털에서 관리자 선택 → 암호 1996 입력. 한 번 들어가면 창을 닫을 때까지 다시 묻지 않습니다.

3. 사용 순서

1 현장 — 입력하고 제출
  • 구역 카드를 눌러 파렛트 수 입력 (구역 전체 또는 로케이션별)
  • 숫자 입력 후 Enter → 적치율 즉시 계산
  • 하단 제출 → 관리자 화면에 자동 반영
  • 날짜 변경은 상단 달력 탭에서
2 관리자 — 확인하고 반영
  • 제출 탭에서 구역별 내역 확인 → 확인
  • 이 수치를 적재수로 반영 → 그날 회차 생성
  • 배치도 탭에서 적치율·재배치 동선 확인
  • 상세·보고 탭에서 엑셀·PDF 내보내기

4. 자주 묻는 것

상황이렇게 하세요
인터넷이 안 될 때입력값은 휴대폰에 임시저장됩니다. 연결되면 다시 제출을 누르세요.
잘못 제출했을 때같은 구역을 다시 입력해 제출하면 덮어씁니다. 관리자가 확인한 뒤에는 확인 취소를 요청하세요.
화면이 예전 그대로일 때앱을 완전히 닫았다 다시 열거나, 홈 화면 아이콘을 지우고 다시 추가하세요.
엑셀·PPT가 안 될 때사내망 차단입니다. PDF는 어떤 망에서도 됩니다.
