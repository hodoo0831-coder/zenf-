# 변경 이력

## worker-api

- **완성본** — 조회·저장·삭제 통합. D1 바인딩·테이블 이름 자동 탐색, CORS 프리플라이트, `Cache-Control: no-store`, `/health` 진단 추가

## worker-site v2

- 삭제 시 서버(`DELETE /records/{id}`)에 요청 후 화면에서 제거
- 통신 실패 시 화면에서도 유지 — 지운 줄 착각 방지
- 「모든 기록 삭제」도 서버 반영
- 삭제 직후 동기화 루프가 기록을 다시 올리는 문제 수정
