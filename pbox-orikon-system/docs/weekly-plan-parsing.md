# 주간계획표 → P-BOX 소요량 인식 규칙

관리자 대시보드 「주간계획」 탭에서 계획표 엑셀을 올리면 일자별 소요량이 자동 입력된다.

## 계획표 구조

- **시트** : 주차별로 분리 (`34주 확정`, `35주 예정` …)
- **날짜** : 상단 병합 헤더가 열 블록을 이룸 (예: `2026.08.18` 이 G~I 열을 덮음)
- **행** : 호기별 (튜브3호 ~ 튜브8호) + 호기별 `합계` 행

## 오더 행 구성

```
Prd오더(C) | 3824190 | 500 | 2500
             오더번호  소요량  생산수량
```

**「생산수량 바로 앞」 숫자가 P-BOX 소요량.**
두 숫자가 한 셀에 함께 들어 있는 경우도 있음 (`500  2500`).

## 인식 규칙 (기본 모드 `order`)

1. `Prd오더` 가 포함된 행만 대상 — 제품코드·제품명 행 제외
2. **7자리 이상 숫자는 버림** — 오더번호(3824190), 제품코드(111271321A)
3. 남은 숫자가 2개 이상이면 → 뒤에서 두 번째가 소요량
4. 숫자가 1개면 건너뜀 — P-BOX를 쓰지 않는 오더
5. `합계` / `소계` 행 제외

## 보조 모드

| 모드 | 방식 | 용도 |
|---|---|---|
| `order` | 오더행 · 생산수량 앞 숫자 | 기본 |
| `red` | 빨간 글씨 숫자 전부 | 서식으로만 구분된 계획표 |
| `qty` | 「생산수량」 텍스트 기준 | 텍스트가 셀에 있는 경우 |

기본 모드가 0건이면 나머지를 자동으로 시도한다.

## 주의

- 제품코드·제품명 행도 **빨간 글씨**라 색상만으로는 소요량과 구분되지 않음
- 적용 전 반드시 **「🔍 인식 상세」** 로 셀 주소·값 대조할 것
- 인식된 날짜가 현재 주차 밖이면 해당 주차로 자동 이동
- 소요량은 브라우저(localStorage)에 주차별로 저장됨 — 기기 간 공유 안 됨
