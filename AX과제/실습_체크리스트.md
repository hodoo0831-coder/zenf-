## 3강 산출물 실행 방법

### 데모(1) 리서치 요약
```
/리서치 2026년 국내외 AX 산업동향
```
수집(서브에이전트) → 요약(Skill) → 노션 → PPT → 출처 검증. 노션 커넥터와 PPT 스킬은 **본인 PC에서 연결된 상태**여야 끝까지 돈다.

### 데모(2) 제안서 초안
RFP 파일 업로드 후
```
/제안서초안
```
검증 단계(요구사항 1:1 대조 + 평가기준 대응)는 생략 불가로 박아 뒀다. 교재 프롬프트 5의 수정사항(평가기준 반영 확인)을 처음부터 반영한 버전이다.

### 데모(3) 축제 수집
```
export DATA_GO_KR_KEY='본인 공공데이터포털 일반 인증키(Decoding)'
python3 scripts/fetch_festivals.py --days 7 --out out/festivals.json
/축제수집 7
```

**인증키 주의** — 교재 43pg에 인쇄된 키는 강의용 공개 키다. 실습은 본인 계정 키로 하고, 키는 환경변수로만 넘긴다. 스크립트·산출물·노션 어디에도 키 문자열이 남지 않도록 설계했다.

**미검증 항목(솔직히)** — `fetch_festivals.py` 는 이 원격 환경에서 `apis.data.go.kr` 아웃바운드가 차단(403)돼 **실제 API 응답으로는 테스트하지 못했다.** 문법·인자 처리·에러 분기까지만 확인했다. 본인 PC에서 첫 실행 시 응답 필드명(`eventstartdate` 등)만 한 번 확인하면 된다.
